# Security policy

## Supported versions

Only the current release candidate branch is supported for security review.

## Reporting vulnerabilities

Do not file public issues for sensitive vulnerabilities. Contact the designated Security Lead out-of-band. The project specification requires naming this person before production release.

## Sensitive data handling

Never include in reports:

- plaintext messages;
- private keys;
- real hints;
- real onion private keys;
- user-identifying metadata.

Use synthetic test data and local test onion services.
